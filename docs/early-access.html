What You Can Do Today

Real capabilities, not just a concept page

Generate structured models

Create bounded functional parts, compositional props, and hybrid objects from a prompt.

Edit and regenerate

Use the right-rail parameter workflow to adjust dimensions and rebuild the model deterministically.

Reopen saved models

Continue editing saved models when plan data is available and keep iterating across sessions.

Export STL

Move from the final artifact to STL export when the model is ready for printing or downstream use.

Timeline

Working alpha now, broader coverage later

Current state: The Windows alpha has real deterministic generation, editing, saved-model reopen, and STL export workflows.

Still limited: Coverage is bounded, not freeform; not every saved model is editable; and some workflows remain alpha-quality.

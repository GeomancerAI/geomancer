System Overview

Plan-first deterministic geometry

Geomancer is built around structured plans, not arbitrary mesh generation.

A prompt is interpreted locally, normalized into a plan, validated, and then built through a deterministic geometry pipeline. That keeps the output predictable, editable, and easier to export or review.

Supported Objects

Bounded object families with clear structure

Functional objects

Brackets, enclosures, mounts, and trays that focus on dimensions, fit, and practical use.

Compositional props

Crates, barrels, canisters, and pedestals built from clean, readable forms.

STL export is available from the final artifact when the model is ready for printing or downstream work.

Style System

Deterministic style, not freeform sculpting

The style system steers the structured output toward minimal, industrial, sci-fi, low-poly, or rounded directions while keeping the geometry deterministic and editable.

Hybrid Generation

Functional forms with added detail

Hybrid builds combine a practical base with surface details, panel cues, bevels, or other stylistic features. That lets Geomancer keep the object useful while still giving it a stronger visual identity.

Editing Workflow

Edit parameters, then regenerate

The right rail is meant for refinement, not one-shot generation.

Adjust dimensions, tweak features, and regenerate from the structured plan. In practice, that means you can refine a model without re-writing the prompt every time you want a smaller hole, a thicker wall, or a different feature layout.

Saved Models

Reopen and keep building

Saved models can be reopened later and edited again when the plan data is present. This keeps the workflow deterministic across sessions and makes it easier to iterate over time.

Limitations

Not every saved model is editable. Reopen-and-edit only works when truthful plan data exists.

Geomancer does not claim freeform or organic sculpting. The current product is centered on structured, bounded geometry.

Blender remains the local handoff target for previewing, refining, or extending the generated result.

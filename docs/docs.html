Step 1

Your First Prompt

Start by installing Geomancer, launching it locally, and opening a new prompt session.

Step 1: Install and Launch Geomancer

Install the Windows alpha, launch the app, and open the chat-style workspace. From there, Geomancer is ready to interpret your request and guide the first model generation flow.

Step 2

Step 2: Describe the Part You Need

Use clear, practical language that explains the shape, purpose, and key constraints of the part.

Example Prompt

"Create a Raspberry Pi 4 enclosure with vents, USB and HDMI cutouts, and 3mm walls."

Step 3

Step 3: Export as STL

Once the generated model looks right, export it as an STL for printing or open it directly in Blender for refinement.

Geomancer is built around a prompt-to-geometry workflow, so the handoff stays simple. Review the model, confirm the printability details, and export the part when you are ready.

Core Concepts at a Glance

Printability: Geomancer surfaces practical checks like wall thickness and general fit before you export.

Dimensions: Describing target sizes helps the geometry engine generate more useful parts on the first pass.

Examples: Common starting points include Raspberry Pi enclosures, gears, and basic brackets.

Prompts: The clearer your prompt is about purpose and constraints, the better the generated starting model.

Export: STL export is the fastest route to slicing, while Blender is available when you want to refine the generated model.
